# 0001. Стек: Python + PySide6 + PyInstaller, без Docker/БД/веба

**Дата:** 2026-10-25

**Контекст.** Стандартный стек владельца (FastAPI + PostgreSQL + React в Docker) рассчитан
на сайты. Уборщик — локальная утилита, которой нужны трей, окна поверх рабочего стола,
доступ к Проводнику и файловой системе.

**Решение.** Python 3.12 + PySide6 (Qt 6), сборка PyInstaller в режиме onedir, настройки —
JSON, журнал — JSON Lines в `%APPDATA%\Uborshchik\`.

**Почему onedir, а не onefile.** onefile распаковывается в TEMP при каждом запуске;
Уборщик сам чистит TEMP и мог бы удалить файлы собственной распаковки.

**Расписание** — внутренний таймер приложения из автозапуска (HKCU\…\Run), а не
Планировщик Windows: нужна всплывашка «через 60 с — отложить?», догон пропущенной уборки
и проверка сроков архива раз в час.

**Пропущенная уборка** (комп выключен в 21:00) догоняется через 5 минут после запуска
программы, а следующая отсчитывается от фактической уборки (+10 дней, в 21:00).
Если комп спал — проверка срабатывает в первую минуту после пробуждения.
