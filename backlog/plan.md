# План

## Этап 1 — MVP (сделано 2026-10-25)
- [x] Ядро: план/выполнение, Guard, архив по датам, срок 90 дней
- [x] Места: рабочий стол, Загрузки, TEMP, корзина, мусор AutoCAD/Revit
- [x] Исключения (имена/маски) для стола и Загрузок
- [x] Зона покоя: рисование мышью, постоянная рамка на столе, чтение позиций значков
- [x] Автозащита облаков (Яндекс Диск из реестра, OneDrive, «Мой диск»)
- [x] Окно: Главная, Что не трогать, Архив, Журнал, Настройки; предпросмотр с галочками
- [x] Трей, автозапуск, расписание раз в 10 дней с всплывашкой «отложить»
- [x] Предупреждение за 7 дней и удаление просроченного архива
- [x] Сборка exe + установка в %LOCALAPPDATA%\Programs
- [x] Тесты ядра
- [x] Догон пропущенной автоуборки через 5 минут после включения
- [x] Исключения: кнопка «Папку…», перетаскивание файлов и папок, автораскладка по спискам, значки папка/файл/маска
- [x] Тон общения: шутки про стройку/проектирование в уведомлениях, заголовках и на кнопках; обращения; переключатель в Настройках (`uborshchik/phrases.py`)

## Идеи на потом
- Восстановление из архива «на место» одной кнопкой (по журналу)
- Несколько зон покоя
- Тёмная тема по системной настройке
- Чистка кэшей программ (браузеры, Autodesk) — только по отдельному согласию
