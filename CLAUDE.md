# Уборщик (cleaner)

Личное Windows-приложение владельца. Владелец работает так: всё рабочее сохраняет
на рабочий стол, а держит рабочие файлы в облаке `C:\Users\Сергей Сарычев\Мой диск`.
Всё остальное на компе — мусор. Уборщик периодически:

- переносит всё с **рабочего стола** и из **Загрузок** в `Рабочий стол\Архив\ГГГГ-ММ-ДД\`
  (Загрузки — в подпапку `Загрузки`), кроме **зоны покоя** и **исключений**;
- удаляет насовсем **мусор AutoCAD/Revit** (только файлы прямо на столе/в Загрузках),
  **TEMP** старше 7 дней, **корзину** старше 30 дней;
- удаляет **папки архива старше 90 дней** (предупреждает за 7 дней);
- запускается **раз в 10 дней** (в 21:00, с всплывашкой «через 60 с — отложить?»)
  и по кнопке «Убрать сейчас» (с просмотром списка).

**Зона покоя** — прямоугольник на рабочем столе (рисуется мышью). Всё, чьи значки
стоят внутри, не убирается. Рамка постоянно видна на столе (полупрозрачная,
клики проходят насквозь, не пропадает по Win+D).

## Стек
Python 3.12, PySide6 (Qt 6), PyInstaller (onedir). Без БД и Docker — локальная утилита
(см. `backlog/decisions/0001-stack.md`). Настройки и журнал — `%APPDATA%\Uborshchik\`
(`settings.json`, `journal.jsonl`).

## Команды
```powershell
.\.venv\Scripts\python.exe -m pytest                     # тесты (только временные папки)
.\.venv\Scripts\python.exe -m uborshchik                 # запустить из исходников
.\.venv\Scripts\python.exe -m uborshchik --dry-run       # план уборки в консоль, ничего не меняет
.\.venv\Scripts\python.exe scripts\shot.py <папка> --preview   # PNG всех экранов для проверки вёрстки
powershell -ExecutionPolicy Bypass -File scripts\build.ps1     # собрать exe и установить
```

## Устройство
- `uborshchik/paths.py` — пути Windows (Known Folders), облака (Яндекс Диск из реестра,
  OneDrive, «Мой диск»), защищённые места, корзины дисков.
- `uborshchik/fsops.py` — **все** операции с диском. `Guard` пропускает только пути
  внутри разрешённых корней и вне защищённых. Ссылки (junction/symlink) не раскрываются.
- `uborshchik/planner.py` — строит `Plan` (список `Action`), ничего не меняя.
- `uborshchik/executor.py` — выполняет план, пишет `RunReport` в журнал.
- `uborshchik/desktop_icons.py` — координаты значков рабочего стола (SysListView32
  Проводника через память процесса explorer) и сопоставление с файлами.
- `uborshchik/recyclebin.py` — корзина напрямую через `$Recycle.Bin\<SID>\$I…/$R…`.
- `uborshchik/schedule.py` — чистая логика расписания.
- `uborshchik/phrases.py` — тон общения: случайные шутливые фразы (`pick`) и постоянные
  подписи кнопок (`btn`, `BUTTONS`), строгий вариант при выключенном юморе. Новые тексты для
  пользователя добавлять сюда (и в FUN, и в PLAIN); кнопки подписывать через `gui/tone.bind`.
- `uborshchik/gui/` — окно (`main_window.py`), предпросмотр (`preview.py`), зона
  (`zone.py`), всплывашка (`countdown.py`), контроллер и трей (`app.py`).

## Правила безопасности (не нарушать)
1. Никакого удаления/переноса мимо `fsops` и `Guard`.
2. Облака и папки, **внутри которых** облако, — не трогать (папка «Облако» на столе
   содержит синхронизируемый `Yandex.Disk`!). Внутрь папок на столе за мусором не ходим.
3. Зона задана, но значки прочитать не удалось → рабочий стол в этот раз **пропускается**.
4. Первая уборка — только вручную через предпросмотр; автоуборка включается после неё.
5. Занятые файлы пропускаются, ничего не перезаписывается (`имя (2).ext`).
6. Тесты работают только во временных папках; на реальной машине — только `--dry-run`.
